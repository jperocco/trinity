# Fantasy Points historical exports

Original receiving advanced CSV exports supplied by the repository owner, archived by season (2021–2025). Upload authorized on 2026-10-09. These files contain premium-source data and are publicly accessible in this repository; this archive does not grant redistribution rights.

The exports are preserved as supplied, without cleaning, deduplication, clipping shares, or imputing missing values. Percent columns use the source's 0–100 scale. Annual exports cannot substitute for weekly observations in a weekly backtest.
